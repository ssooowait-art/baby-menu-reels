# 야생의 어둠 — 생존 (Wild Darkness-inspired Survival)

The Wild Darkness에서 영감을 받은 장르 메커니즘의 **오리지널 아이소메트릭 생존 게임**입니다.
모든 그래픽·데이터·코드는 자체 제작(캔버스 절차적 드로잉)이며 외부 에셋이 없습니다.
브라우저만 있으면 실행됩니다 — 별도 빌드/설치 불필요.

## 실행 방법

- `index.html`을 브라우저로 열면 바로 플레이됩니다.
- 또는 로컬 서버: `python3 -m http.server` 후 `http://localhost:8000` 접속.
- 모바일 터치 / 데스크톱 마우스 모두 지원.

## 📱 모바일 앱으로 설치 (PWA)

이 게임은 PWA라서 홈 화면에 설치하면 전체화면·오프라인으로 앱처럼 실행됩니다.

1. **배포**: `main` 브랜치에 머지하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
   (저장소 Settings → Pages → Source를 **GitHub Actions**로 한 번만 설정)
2. **설치**: 배포된 주소를 휴대폰 브라우저로 열고 —
   - **Android(Chrome)**: 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
   - **iPhone(Safari)**: 공유(⬆) → "홈 화면에 추가"
3. 설치 후에는 인터넷 없이도 플레이되고(서비스 워커 캐시), 진행 상황은 기기에 저장됩니다.

## ✨ 픽셀 이펙트 (PixelFX)

`js/pixelfx.js` — 이미지 없이 코드로 그리는 픽셀 VFX 엔진(27종: 불·연기·타격·채집·물·버프·아이템·어둠·얼음·번개·마법·상태).
게임 안 타격/피격/채집/레벨업/제작/동굴 출입/보스 파동/모닥불 불티/빗방울/발걸음 먼지에 연결돼 있습니다.

- **갤러리**: `fx.html` (설정 → ✨ 이펙트 갤러리) — 전부 미리보기, 팔레트 교체
- **다른 웹 게임**: `PFX.createSystem({px:4}).spawn('fire/burst', x, y, { palette: 'ice', scale: 1.5 })`
- **고도·유니티 등**: 갤러리의 `PNG` 버튼 → 투명 스프라이트 시트 + Aseprite 형식 JSON

## 게임 방법

- **이동/채집**: 땅을 탭하면 이동, 자원을 탭하면 채집합니다.
- **도구**: 나무는 돌도끼 🪓, 바위는 돌곡괭이 ⛏ 가 있어야 캘 수 있습니다.
- **생존 스탯**: HP · 에너지 · 배고픔 · 갈증 · 피로 · 체온을 관리하세요.
  물가를 탭하면 물을 마시고, 음식은 가방에서 먹습니다.
- **낮과 밤**: 밤에는 어둠이 내려오고 **어둠의 정령**이 나타납니다.
  횃불을 들거나 모닥불 곁에 있으면 안전합니다.
- **제작**(⚒): 돌도끼 → 횃불 → 모닥불 → 화덕/침낭 순으로 발전하세요.
  모닥불 근처에서는 요리가 가능하고, 침낭을 탭하면 아침까지 잠을 잡니다.
- **사냥**: 낮에는 토끼(도망감)와 멧돼지(반격함)가 돌아다닙니다 → 생고기·가죽.
- **낚시**: 낚싯대를 장착하고 물을 탭하면 낚시. 구운 생선은 훌륭한 식량.
- **농사**: 밭을 설치하고 콩을 심으면 자라납니다. 비가 오면 더 빨리 자랍니다.
- **제련**: 바위에서 철광석 → 화덕에서 철괴 → 철도끼·철곡괭이(더 강하고 오래감).
- **장비**: 가죽옷(방어+보온), 물주머니(물 휴대), 어둠의 파편으로 만드는
  **정령의 등불**(꺼지지 않는 광원)과 **어둠의 검**(최강 무기).
- **날씨**: 비가 오면 체온이 떨어지고 불이 빨리 꺼지지만 작물은 빨리 자랍니다.
- **밤의 위협**: 날이 갈수록 어둠의 정령이 늘어나고, 3일차 밤부터는
  모닥불도 두려워하지 않는 **어둠의 늑대**가 나타납니다.
- **유적과 미스터리**: 섬에는 먼저 온 자의 흔적이 있습니다 — 고인돌·무너진 석실,
  그리고 밤에만 보랏빛으로 빛나는 검은 오벨리스크. 조사하면 잃어버린 **설계도**
  (수호 장승 = 밤의 것들이 접근 못 함, 빛의 화로 = 꺼지지 않는 불)와
  **먼저 온 자의 일기**를 얻습니다. 일기 12장(📖)을 모으면 이 섬의 어둠의
  정체가 밝혀집니다. 오벨리스크에는 파편 3개를 봉헌해야 하며… 그 보상은 직접 확인하세요.
- **심연(던전)**: 섬 어딘가의 **동굴 입구**로 들어가면 지하 세계가 펼쳐집니다.
  항상 칠흑이라 **광원 장착이 필수**이며, 어둠 수정(파편)·금맥·박쥐가 기다립니다.
  가장 깊은 곳의 **심연의 문**은 일기 12장 + 별의 심장 + 레벨 5를 갖춰야 열리고,
  그 너머에 최종 보스 **깨어난 어둠**이 있습니다 — 빛 속에서 싸우면 더 큰 피해를 줍니다.
  승리 후에는 **두 가지 엔딩**(심장 파괴 / 심장 봉인) 중 하나를 선택합니다.
- **미션**: 좌측 상단의 미션을 따라가면 자연스럽게 생존 기반을 갖추게 됩니다 (23단계).
- **성장**: 채집·제작·전투로 경험치를 얻어 레벨업(최대 HP/능력치 상승).
- 진행 상황은 브라우저에 **자동 저장**됩니다(설정에서 초기화 가능).

## 구조

```
index.html      # 마크업 + HUD/패널 DOM
css/style.css   # UI 스타일
js/data.js      # 아이템·레시피·미션·몬스터 데이터
js/sprites.js   # 절차적 스프라이트/아이콘 (전부 코드로 그림)
js/game.js      # 월드 생성·이동·채집·전투·낮밤·UI·저장
```
